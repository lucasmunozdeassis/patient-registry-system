# Patient Registry System

A lightweight, CLI-based patient management system built with Python. Designed to streamline registry procedures, manage consultations, and persist patient records cleanly using JSON storage.

## Features

- **User Authentication**: Secure access control requiring standard login credentials.
- **Patient Registration**: Add new patient records with distinct parameters.
- **Record Management**: Query existing patients, view schedules, and inspect registry data.
- **Data Persistence**: Automatic reading and writing to `patients.json` to keep data intact between sessions.

## Tech Stack

- **Language**: Python 3.x
- **Storage**: JSON
